# car-dumper
# C 型折返式翻车机 · 3D 工艺演示

在浏览器里观察铁路敞车如何进机、压紧、翻卸和折返，以及卸下的煤如何进入料场或配煤仓。项目使用 Three.js r170 构建三维场景，支持鼠标和触屏操作。模型尺寸、动作时序和煤流用于教学演示。

## 快速开始

| 页面 | 内容 | 打开方式 |
| --- | --- | --- |
| 系统总览 | 翻卸、空车折返和料场煤流 | 在本地静态服务中打开 [index.html](index.html) |
| 本体详解 | 点选部件、切换车皮、逐步观察翻卸 | 下载并双击 [dumper-detail.html](dumper-detail.html) |

使用支持 WebGL 2 的浏览器。两份离线 HTML 已包含渲染依赖，下载后即可打开。

体验完整系统时，在下载或克隆后的项目根目录启动静态服务。总览通过 CDN 加载 Three.js。


## 系统总览

仿真打开后自动运行。拨车机牵引重车入机，翻车机在压车梁和靠车板锁定车体后翻转约 165°。上一节空车经迁车台移到空车线，再由推车机送入空车列。

- 控制栏可暂停、继续、调整 0.25–4 倍速、切换视角和显示标签。「本体详解」按钮打开独立的部件演示。
- 桌面用左键拖动旋转、右键拖动平移、滚轮缩放。手机用单指旋转、双指捏合缩放，并通过下拉菜单切换视角。点「状态」可展开设备信息。
- 料场支持自动、堆料、取料和直通。切换工况时会演示共用皮带排空和悬臂转位。

| 工况 | 主要煤流 |
| --- | --- |
| 堆料 | 翻车机煤斗 → B01 → B02 → 转运站 → B03 → 固定尾车与悬臂 → A 煤堆 |
| 取料 | B 煤堆 → 斗轮与悬臂 → B03 → B04A → B04B → B02 → 转运站 → B06 → 配煤仓 |
| 直通 | 翻车机煤斗 → B01 → B02 → 转运站 → B06 → 配煤仓 |

总览支持 `t`（启动时快进的仿真秒数）、`view`（视角）和 `yard`（初始料场工况）。例如在本地静态服务中打开 `index.html?yard=reclaim&view=stacker`，可从堆取料机视角观察取料。

## 翻车机本体详解

可观察 C 形端环、液压压车梁和靠车板、弧形轨道与齿圈、均衡托轮、驱动电机、减速机和承车平台。点选模型或部件索引可高亮并聚焦部件，也可使用端面、传动侧和靠车侧预设视角。

1. 选择「无车皮」观察机构，或选择「有车皮」查看敞车和落煤动画。
2. 点「播放循环」观看待机、压紧、翻转、卸料、回位和松开。也可点任一工步从头播放，该步结束后会自动暂停。
3. 拖动时间轴定位到指定姿态，观察齿轮啮合、托轮滚动和油缸伸缩。
# 独立翻车机操作仿真

构建：`node operation/build.mjs`。逻辑验证：`node --test operation/controller.test.mjs`。

- `controller.mjs`：可确定性推进的作业状态、31 个工步、三种模式、车钩接触、联锁、停止/恢复和故障注入。
- `scene.js`：从原总览复制的翻车机、拨车机、迁车台、推车机与车辆模型，仅读取本页状态。
- `main.js`：操作台交互、点动、诊断和日志。
- `index.html`：新页面布局与样式；运行源码需构建，发布使用根目录生成的独立 HTML。

所有五个设备分区始终展开，按钮使用简写；绿色小灯表示实际到位或开，熄灭表示反之，允许操作与状态显示分别计算。

每个卡片独立选择自动、手动、点动。各设备各自保存动作和进度，允许不同设备同时运行。卡片停止或切换模式只影响本机，集中停止、急停及故障保护作用于全线。手动点击运行至到位，点动必须按住、松开或失焦停止本机；页面进入后台停止全线。

自动跟随根据传感状态调度：备妥后自动设备待命，集中启动可开始自动拨车和恢复自动设备。拨车机手动送车入机、脱钩、抬臂或退出后，自动翻车机自行压靠、翻卸并回零。迁车台、推车机和夹轮器也按各自模式与现场条件接续。自动设备等待手动设备提供必要反馈，不会接管手动设备。

点动放宽设备工艺顺序，但保留核心联锁：机内有车（包括正在进入平台的车辆）时，压车和靠车必须同时到位才能正翻或回翻；离开零位后不能松压、松靠；迁车台必须拔销到位才能横移。上述信号运行中丢失会保护停机。仍支持无车压靠、无车无压靠空翻、拔销后的空台横移和无车推车等，翻转范围为 0–175°；「机内车」可在点动停机回零后切换。电源、液压、急停和故障保护仍生效。故障信号恢复和复位不会自动开机。

重车钩和空车钩各一个开关：开钩碰车后自动闭合，闭合挂住后可以牵引；点击切换为开才脱开。原地开钩后保持脱开，离开再碰车才重新挂上。空车钩使用相同规则。止挡器为无电气、无液压的被动机械设备，只随台面实际对轨升降，和插销、对位电气信号、供电无关，不提供手动止挡按钮。所有模式均对真实轮对位置做扫掠碰撞检测，升起止挡会挡停车轮及相连车列、牵推设备；长时间步也不能穿挡。挡停不触发虚构的电气故障，对轨后可继续，车辆跨接期间台体保持支承。

自动与手动的主要联锁：辅助系统备妥；压靠位置和夹持压力；拨车机退让；进出口光电；煤斗料位和下游输送；迁车台对轨及插销、台上夹轮器、重空线止挡、推车机原位。

参考现场照片、中国航海学会 T/CIN 091—2025、CN117303029A 折返工艺；止挡机械形式依据现场反馈。165°工作终点、点动175°、10 MPa、85%料位以及动作时长都是仿真设定，无实机 PLC 或控制连接，不能替代现场规程。

部署仅新增 `~/apps/car-dumper-3d/dumper-operation.html`，无需修改原站页面或重启原服务；URL 为 `https://car.home.tanxm.com/dumper-operation.html`。导航页在现有翻车机卡片上新增「操作仿真」链接，保留原总览入口及其他卡片。

页面右上角可切换浅色 / 深色，主题会保存在本浏览器。总览页新增「前往仿真操作」入口，发布时总览仅追加该链接，保留线上本地 vendor 配置及其他内容。

止挡器的抬起、落下使用随迁车台位移变化的平滑机械凸轮动画，挡块、连杆、滚轮和配重同步动作；台体暂停或反向时连续跟随。动画不改变实际对轨判断或车轮阻挡规则。

手动翻卸按实际状态完成：高角度停留和回翻期间余煤继续自然落下，卸空后计数一次，不要求额外点「卸净」。回零并松压靠后本车循环按状态结束；拨车机提前回原位并挂好下一车时保留车钩状态，下一次「前进」执行新车牵引，避免被旧的送空车工步锁住。未实际卸净的车仍不能结束循环。
## 开发与构建

构建离线文件需要 Node.js 18 或更高版本及 npm。在项目根目录运行以下命令。

```bash
npm ci
npm run build:detail
npm run build
```

| 命令 | 输入 | 生成文件 |
| --- | --- | --- |
| `npm run build:detail` | [detail/](detail/) | `dumper-detail.html` |
| `npm run build` | [index.original.html](index.original.html) | `c-dumper.html` |

系统总览直接编辑 [index.html](index.html)。详解的布局在 [detail/index.html](detail/index.html)，部件建模在 [detail/machine.js](detail/machine.js)，工步和姿态计算在 [detail/motion.js](detail/motion.js)，交互在 [detail/main.js](detail/main.js)。[构建脚本](build-standalone.mjs) 使用 esbuild 将脚本和依赖内嵌到离线 HTML。

发布静态站点时，将 `index.html` 与生成的 `dumper-detail.html` 放在同一目录，两个页面可通过相对链接互相跳转。
